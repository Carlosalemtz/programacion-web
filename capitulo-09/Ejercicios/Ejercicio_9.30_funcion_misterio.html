Ejercicio 9.30: ¿Qué hace la función misterio?

¿Qué hace la siguiente función?

// El parámetro b debe ser entero
// positivo para evitar recursividad infinita
function misterio( a, b )
{
   if ( b == 1 )
      return a;
   else
      return a + misterio( a, b - 1 );
}
Respuesta: calcula de forma recursiva el producto a × b, sumando a consigo mismo b veces. Por ejemplo, misterio( 4, 3 ) = 4 + 4 + 4 = 12.
