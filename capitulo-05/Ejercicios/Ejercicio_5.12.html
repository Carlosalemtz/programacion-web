Computadoras, hardware y software

Una introducción a la tecnología actual

Por: Ale

Una computadora es una máquina capaz de recibir datos, procesarlos siguiendo instrucciones y entregar resultados. Hoy en día incluso un teléfono económico ejecuta millones de operaciones por segundo, algo impensable para quienes trabajaron con las primeras computadoras de la década de 1940.

El software es el conjunto de programas que le indican al equipo qué debe hacer. Quienes escriben esas instrucciones son los programadores, y el lenguaje que elijan influye en qué tan fácil resulta mantener y hacer crecer un sistema con el paso del tiempo.

El hardware, en cambio, es todo lo que se puede tocar: procesador, memoria, almacenamiento, teclado, pantalla y tarjetas de red. Gracias a la miniaturización, componentes que antes ocupaban habitaciones enteras hoy caben en un chip del tamaño de una uña.

Los microprocesadores también viven dentro de objetos que no parecen computadoras: automóviles, lavadoras, cámaras de seguridad, relojes y hasta termostatos. A esta idea se le conoce como sistemas embebidos y es una de las áreas de mayor crecimiento en la ingeniería.

La Web nació como una forma de compartir documentos y terminó convirtiéndose en una plataforma de aplicaciones. HTML da la estructura, CSS se encarga de la presentación y JavaScript aporta el comportamiento de cada página.
