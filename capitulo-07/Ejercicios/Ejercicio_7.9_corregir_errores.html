Ejercicio 7.9: Identificar y corregir errores

Identifique y corrija los errores en cada uno de los siguientes segmentos de código.

a)

if ( edad >= 65 );
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65 )";
Errores: el punto y coma después de la condición del if (termina el if con una instrucción vacía y el else queda sin if); en el último writeln la comilla de cierre está después del paréntesis. 
if ( edad >= 65 )
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65" );

b)

var x = 1, total;
while ( x <= 10 )
{
   total += x;
   ++x;
}
Error: total no se inicializa, por lo que el resultado es NaN. 
var x = 1, total = 0;
while ( x <= 10 )
{
   total += x;
   ++x;
}

c)

var x = 1;
var total = 0;
while ( x <= 100 )
   total += x;
   ++x;
Error: faltan las llaves del cuerpo del while; ++x nunca se ejecuta dentro del ciclo y se produce un ciclo infinito. 
while ( x <= 100 )
{
   total += x;
   ++x;
}

d)

var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   ++y;
Errores: la variable de control se incrementa en lugar de decrementarse (ciclo infinito) y falta la llave derecha de cierre. 
var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   --y;
}
