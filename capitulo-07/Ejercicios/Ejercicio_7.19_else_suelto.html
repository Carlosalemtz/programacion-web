Ejercicio 7.19: El problema del else suelto

Determine la salida de cada segmento cuando x es 9 y y es 11, y cuando x es 11 y y es 9.

a)

if ( x < 10 )
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
   else
      document.writeln( "<p>#####</p>" );
document.writeln( "<p>$$$$$</p>" );
x = 9, y = 11 → ***** y $$$$$
x = 11, y = 9 → sólo $$$$$ (el else pertenece al if interno)

b)

if ( x < 10 )
{
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
}
else
{
   document.writeln( "<p>#####</p>" );
   document.writeln( "<p>$$$$$</p>" );
}
x = 9, y = 11 → sólo *****
x = 11, y = 9 → ##### y $$$$$
