Ejercicio 7.21: Múltiplos de 2 (ciclo infinito)

Muestre de forma continua los múltiplos del entero 2 (2, 4, 8, 16, 32, 64, ...). El ciclo no debe terminar. ¿Qué ocurre cuando ejecuta este programa?

Código del ciclo infinito pedido:

var valor = 2;
while ( true )
{
   document.writeln( valor + " " );
   valor *= 2;
}
¿Qué ocurre? El navegador se queda "congelado": el ciclo nunca termina, la página no termina de cargarse y, después de un tiempo, el navegador avisa que la página no responde y ofrece detenerla. Además, después de 21023 el valor ya no cabe en un número de JavaScript y se muestra Infinity indefinidamente.
