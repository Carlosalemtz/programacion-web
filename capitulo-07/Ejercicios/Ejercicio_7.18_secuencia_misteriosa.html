Ejercicio 7.18: Secuencia de comandos misteriosa (filas y columnas)

Sin ejecutarla, determine lo que imprime la secuencia de comandos.

var fila = 10;
var columna;

while ( fila >= 1 )
{
   columna = 1;
   document.writeln( "<p>" );

   while ( columna <= 10 )
   {
      document.write( fila % 2 == 1 ? "<" : ">" );
      ++columna;
   } // fin de while

   --fila;
   document.writeln( "</p>" );
} // fin de while
