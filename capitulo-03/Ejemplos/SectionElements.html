Java How to Program, 9/e

Tomado de Java How to Program, 9/e:
Entre sus características se incluyen:
  • Amplia cobertura de los fundamentos, que incluye dos capítulos sobre instrucciones de control.
  • Énfasis en ejemplos del mundo real.
  • Conjunto de ejercicios "Hacer la diferencia".
  • Introducción temprana a clases, objetos, métodos y cadenas.
  • Manejo de excepciones integrado.
  • Archivos, flujos y serialización de objetos.
  • Secciones modulares opcionales sobre las características del lenguaje y de las bibliotecas del nuevo Java SE 7.
  • Otros temas incluyen: recursividad, búsqueda, ordenamiento, colecciones genéricas, genéricos, estructuras de datos, applets, multimedia, multihilos, bases de datos/JDBC™, desarrollo de aplicaciones web, servicios web y un caso de estudio opcional de diseño orientado a objetos de un cajero automático.
