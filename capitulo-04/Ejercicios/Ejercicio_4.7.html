El desarrollo web hoy

Front-End: Tiene que ver con la estructuración de documentos usando HTML5 y el estilo de documentos usando CSS3. También se le conoce como el lado del cliente porque brinda la plataforma de interacción entre los clientes (navegadores web como IE y Firefox) y los usuarios.

Back-End: Tiene que ver con la interacción entre los navegadores web y los servidores, así como con escribir y obtener datos de bases de datos. Hoy en día se usan muchos lenguajes de back-end, entre ellos PHP, PYTHON, JAVA, etc. La base de datos más usada es MySQL.
