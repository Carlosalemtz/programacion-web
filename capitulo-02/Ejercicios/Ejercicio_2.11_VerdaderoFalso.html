Ejercicio 2.11 - Verdadero o falso

  1. Un documento de HTML5 válido no puede contener letras mayúsculas en nombres de elementos.

    Falso. HTML5 permite nombres de elementos en mayúsculas, minúsculas o mezcla de ambas; sin embargo, se recomienda usar minúsculas por convención y legibilidad.

  2. Los documentos de HTML5 pueden tener la extensión de archivo .htm.

    Verdadero. Tanto .html como .htm son extensiones válidas para documentos de HTML5.

  3. &less; es la referencia a entidad de carácter para el carácter menor que (<).

    Falso. La referencia de entidad correcta para el carácter menor que es &lt;, no &less;.

  4. En un documento de HTML5 válido, <li> puede anidarse dentro de etiquetas <ol> o <ul>.

    Verdadero. El elemento li siempre debe estar contenido dentro de un elemento ol (lista ordenada) o ul (lista desordenada).
