Ejercicio 6.12: Instrucciones que modifican variables

¿Cuál de las siguientes instrucciones de JavaScript contiene variables cuyos valores se modifican?

a) p = i + j + k + 7; → Sí, se modifica el valor de p.
b) window.alert( "variables cuyos valores se destruyen" ); → No, sólo muestra una cadena.
c) window.alert( "a = 5" ); → No, sólo muestra una cadena.
d) cadenaVal = window.prompt( "Escriba una cadena:" ); → Sí, se modifica el valor de cadenaVal.
Respuesta: las instrucciones a) y d).
