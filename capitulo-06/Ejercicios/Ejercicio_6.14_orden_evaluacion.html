Ejercicio 6.14: Orden de evaluación de operadores

Indique el orden de evaluación de los operadores en cada instrucción y muestre el valor de x después de ejecutarla.

a) x = 7 + 3 * 6 / 2 - 1;
3 * 6 = 18 → 18 / 2 = 9 → 7 + 9 = 16 → 16 - 1 = 15 → x = 15
b) x = 2 % 2 + 2 * 2 - 2 / 2;
2 % 2 = 0 → 2 * 2 = 4 → 2 / 2 = 1 → 0 + 4 = 4 → 4 - 1 = 3 → x = 3
c) x = ( 3 * 9 * ( 3 + ( 9 * 3 / ( 3 ) ) ) );
9 * 3 = 27 → 27 / 3 = 9 → 3 + 9 = 12 → 3 * 9 = 27 → 27 * 12 = 324 → x = 324
