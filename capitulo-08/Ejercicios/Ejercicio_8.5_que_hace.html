Ejercicio 8.5: ¿Qué hace el programa?

¿Qué es lo que hace el siguiente programa?

document.writeln( "<table>" );

for ( var i = 1; i <= 10; i++ )
{
   document.writeln( "<tr>" );

   for ( var j = 1; j <= 5; j++ )
      document.writeln( "<td>(" + i + ", " + j + ")</td>" );

   document.writeln( "</tr>" );
} // fin de for

document.writeln( "</table>" );
Respuesta: crea una tabla de 10 filas por 5 columnas; cada celda muestra el par (fila, columna), desde (1, 1) hasta (10, 5). El ciclo externo genera las filas y el interno las columnas de cada fila.
