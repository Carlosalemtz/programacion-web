Ejercicio 8.4: Encontrar los errores

Encuentre el error en cada uno de los siguientes segmentos de código (puede haber más de un error).

a)

For ( x = 100, x >= 1, ++x )
   document.writeln( x );
Errores: For debe escribirse en minúsculas; las partes del encabezado se separan con punto y coma, no con comas; y como el ciclo va de 100 a 1, la variable debe decrementarse (--x), si no el ciclo es infinito. 
for ( x = 100; x >= 1; --x )
   document.writeln( x );

b)

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
   case 1:
      document.writeln( "Entero impar" );
}
Error: falta break en el case 0, por lo que con un número par también se imprime "Entero impar". 
switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
}

c) Debe imprimir los enteros impares del 19 al 1

for ( x = 19; x >= 1; x += 2 )
   document.writeln( x );
Error: la variable debe decrementarse en 2, no incrementarse (ciclo infinito). 
for ( x = 19; x >= 1; x -= 2 )
   document.writeln( x );

d) Debe imprimir los enteros pares del 2 al 100

contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} While ( contador < 100 );
Errores: While debe ir en minúsculas y la condición debe ser <= 100 para que también se imprima el 100. 
contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
